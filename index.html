How to use

Choose a tool, tap/click on the pitch to add items, or use Select/Edit to move them around.
Edit controls
• Drag an item to move it
• Use the corner handle to resize
• Use the top handle to rotate
Shortcuts (desktop)
Del Delete selected
Ctrl + Z Undo
Ctrl + Y Redo
Esc Deselect
